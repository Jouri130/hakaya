Hakaya – AI-Powered Arabic Story Generator

Hakaya is an AI-powered storytelling application developed during Arabthon 2026. The project aims to generate personalized Arabic stories for children, inspired by cultural heritage and designed to provide an engaging storytelling experience.

Project Overview

Hakaya explores how artificial intelligence can support Arabic storytelling by generating stories for children while considering cultural context and age-appropriate content.

The project was developed from scratch by Team Hakaya and presented to the judging panel at Arabthon 2026.

Key Objectives

* Generate Arabic stories for children using AI.
* Explore the use of AI to support culturally inspired storytelling.
* Provide an interactive application for generating stories.
* Experiment with fine-tuning language models to improve generated outputs.
